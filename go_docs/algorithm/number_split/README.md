# 数字分解为和为偶数的两数问题

## 问题描述

给定一个正整数 n，将其分解为两个正整数的和，使得这两个数的和为偶数。求有多少种不同的分解方法？

## 数学分析

### 核心洞察

两个数的和为偶数，当且仅当：
- 两个数都是奇数，或
- 两个数都是偶数

### 关键发现

**如果 n 是奇数，则无解！**

原因：
- 如果 n = a + b 且 a + b 为偶数
- 那么 a 和 b 必须同为奇数或同为偶数
- 但两个奇数的和是偶数，两个偶数的和也是偶数
- 这与 n 是奇数矛盾

**如果 n 是偶数，则有解！**

分解方法数 = n/2

### 证明

对于偶数 n：
- 可以分解为：(1, n-1), (2, n-2), ..., (n/2, n/2)
- 其中满足和为偶数的分解有 n/2 种

## 算法实现

### 最简洁版本（O(1) 时间复杂度）

```go
func CountEvenSumSplitsSimple(n int) int {
    if n <= 0 || n%2 == 1 {
        return 0
    }
    return n / 2
}
```

### 完整版本

```go
func CountEvenSumSplits(n int) int {
    if n <= 0 {
        return 0
    }
    
    // 如果n是奇数，无法分成两个和为偶数的数
    if n%2 == 1 {
        return 0
    }
    
    // 如果n是偶数，分法数就是 n/2
    return n / 2
}
```

## 示例

| n | 结果 | 分解方法 |
|---|------|----------|
| 2 | 1 | (1,1) |
| 3 | 0 | 无解 |
| 4 | 2 | (1,3), (2,2) |
| 5 | 0 | 无解 |
| 6 | 3 | (1,5), (2,4), (3,3) |
| 8 | 4 | (1,7), (2,6), (3,5), (4,4) |
